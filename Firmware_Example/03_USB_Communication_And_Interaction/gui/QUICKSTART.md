# 快速开始指南

## 30秒快速开始

### 1. 安装依赖 (一次性)
```bash
pip install -r requirements.txt
```

### 2. 运行程序
**Windows:**
```bash
run.bat
```

**Linux/Mac:**
```bash
python main.py
```

### 3. 使用
1. 点击「刷新」按钮找到 USB 设备
2. 选择端口并点击「连接」
3. 設定位置和速度，点击「移动到目标」

## 基本操作

| 功能 | 操作 |
|------|------|
| 连接设备 | 选择端口 → 点击「连接」 |
| 移动到某位置 | 输入位置/速度 → 点击「移动到目标」 |
| 设置速度 | 输入速度值 → 点击「设置速度」 |
| 回零 | 点击「回零」或「全部回零」 |
| 紧急停止 | 点击「停止」或「全部停止」 |
| 查看轨迹 | 右侧图表实时显示移动轨迹 |
| 清除轨迹 | 点击「清除轨迹」 |

## 常见问题

**Q: 找不到 USB 设备？**  
A: 检查硬件连接和电源，点击「刷新」重新扫描

**Q: 连接成功但无法控制？**  
A: 检查固件是否支持该通信协议

**Q: 运动不顺畅（有停顿）？**  
A: 这可能是硬件设计的特性，检查固件的轨迹规划
